# 📈 TSLA Day Trading 學院

由 Level 1 到 Level 9 嘅美股 Day Trading **互動學習平台**（廣東話）。內容整理自自己生成嘅 Level 1–5 課程筆記同實戰問答，再加上進階 Level 6–8、VCP 專題 Level 9、補充章節、互動計算器、模擬交易練習場、K 線重播、訓練場、測驗、錯題本同交易日誌。

> ⚠️ 所有 TSLA 價格、成交量同交易例子都係**教學模擬**，唔係即時行情、唔係投資建議、亦唔係已驗證嘅盈利策略。

## 🚀 點樣用

### 方法 1：GitHub Pages（建議）

1. 將呢個 repo push 上 GitHub。
2. 去 repo 嘅 **Settings → Pages**。
3. **Source** 揀 **Deploy from a branch**，Branch 揀 `main`、資料夾揀 `/ (root)`，撳 Save。
4. 等一兩分鐘，網址會係 `https://<你嘅帳號>.github.io/<repo 名>/`。

### 方法 2：自己部機

純前端、唔使安裝任何嘢。喺資料夾入面行：

```bash
python3 -m http.server 8000
```

然後打開 <http://localhost:8000>。（直接雙擊 `index.html` 大部分功能都用得，但離線快取需要用 http 開。）

## 🔐 登入同家庭同步（Firebase）

同 nursing-tracker 一樣，用 **Google 帳號登入**，資料儲存喺學院專用嘅 Firebase 專案 **`tsla-academy`**（Firestore，香港 asia-east2），即時同步。用自己嘅專案，免費額度同 nursing-tracker 分開，互不影響：

- 只有 `js/cloud-config.js` 入面 `members` 嘅 email 可以登入（而家係 Bill、Ivan、Man 同志強），其他帳號會見到「冇權限」。
- 每人嘅進度、書籤、筆記、螢光筆、測驗、交易日誌**分開儲存**；**全家睇到，但每人只可以改自己嘅**。
- 章節入面會見到家人嘅螢光筆（佢顏色嘅波浪底線，標明邊個）、書籤、筆記同「讀到呢度」；主頁同家庭進度有「家人動態」；「我的」頁可以揀睇我／家人／全家。
- 同一個人用幾部機都會自動同步；離線都用得，連線後再上載。
- 第一次登入時，如果部機有舊紀錄（本機模式，或者之前喺 nursing-declan 專案嘅雲端快取），會問你要唔要合併入你嘅帳號。

### 一次性設定：Firestore 規則

Firebase Console → tsla-academy → **Firestore Database → 規則（Rules）**，貼上 [`firestore.rules`](firestore.rules) 嘅內容再發佈（已經設定好）。規則保證只有授權 email 可以讀寫，而且每人只可以改自己嘅資料。

### Alpaca 市場數據金鑰

去 ⚙️ 設定 →「📈 市場數據（Alpaca）」輸入 API Key ID 同 Secret（建議用 Paper 帳戶嘅金鑰）。雲端模式下金鑰存喺 Firestore `academyConfig/alpaca`，只有成員讀到、只有 Bill 可以改；**唔會**放入呢個公開 repo。

### 加／減家庭成員

1. 改 `js/cloud-config.js` 嘅 `members`（email、名稱、頭像、顏色）。
2. 改 `firestore.rules` 入面 `academyFamily()` 嘅 email 清單，再喺 Console 發佈。

### 備份

設定頁仍然可以匯出 `.json` 備份，亦可以將舊備份入面某個使用者合併入你嘅帳號。

## ✏️ 點樣改內容

課程內容用 Markdown 寫喺 `content/*.js`，另外有幾個特別語法：

| 語法 | 效果 |
|---|---|
| `## 3.4 標題` | 小節（自動出現喺目錄，可以加書籤／筆記） |
| `:::warn 標題` … `:::` | 提示框（`warn` `info` `tip` `key` `coach` `good` `bad` `bar` `card` `steps`） |
| `$$ 公式 $$` | 公式框 |
| `[[tool:possize-pro]]` | 嵌入計算器（名稱見 `js/tools.js`） |
| `[[quiz:l3-c3]]` | 嵌入測驗（題目喺 `js/data-quizzes.js`） |
| `[[check:l3-plan]]` | 可剔清單 |
| `[[chart:l3-breakout]]` | K 線示意圖（喺 `js/charts.js`） |
| `[[rr:386.10,384.70,388.90]]` | Entry / Stop / Target 風險回報圖 |
| `[[replay:l3-br-win]]` | K 線重播遊戲入口 |
| `[[widget:res-outcomes]]` | 內文示意圖（名稱見 `js/tools.js` 嘅 `WIDGETS`） |

改完 push 上 GitHub，Pages 會自動更新。
